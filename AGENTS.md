# Agent Instructions

Agents are not authorized to modify code or any other files in this repository.

Agents may only:

- Read and inspect repository contents.
- Analyze the codebase and its behavior.
- Report findings, explanations, and recommendations to the user.

Agents must not edit, create, delete, rename, move, format, or otherwise change repository files. They must not commit, push, or perform any other operation that changes the repository, its working tree, or its Git state.

If a requested task would require a change, the agent must stop after analysis and explain the proposed change without implementing it.
